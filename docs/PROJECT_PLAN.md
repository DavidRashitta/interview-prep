# Business & Build Plan — AI Interview Prep Tool

Full roadmap, prototype through advertising. Built with AI assistance, ~€1,000 starting budget.
The biggest investment is **time**, not money. All figures are rough estimates in euros.

## Strategic context

AI has disrupted the technical-interview landscape. Companies are shifting away from
traditional algorithm grinding toward AI-assisted coding rounds, code comprehension,
debugging, and system design — while most candidates still prepare with outdated material.
That gap is the opening this tool is built to fill. A niche newsletter serves as the free
marketing channel that feeds users to the tool. Credibility comes from the **product working**,
not from the founder's interview résumé — which is why the build is a tool, not coaching.

## Phase 0 — Prototype  *(Week 1, ~1–2 weeks)*

Build a working AI interviewer for **one** interview type. It runs a realistic mock session
and gives feedback at the end. Goal: prove the concept and feel how it should work.

**Cost: ~€0–30** — a few euros of AI API usage for testing, plus a free hosting tier.

## Phase 1 — Validate demand  *(Weeks 2–4, in parallel)*

Register a domain, put up a simple landing page with an email sign-up, and launch the
newsletter. Post in communities (r/cscareerquestions, r/leetcode, LinkedIn, X) to collect
waitlist sign-ups.

**Cost: ~€15–40 total** — domain ~€12/yr; landing page free–€20/yr; newsletter free tier.
**The gate:** if sign-ups come in, build. If silence, adjust the angle before coding for weeks.

## Phase 2 — Build the MVP  *(Weeks 4–10)*

Turn the prototype into something usable and payable: accounts, a polished interview flow,
a clean feedback report, payments. One interview type done really well, not five halfway.

- Hosting & database: free tier to start (Vercel + Supabase), ~€20–40/mo as it grows.
- Payments: Stripe — no monthly fee, ~2.9% + €0.30 per transaction.
- AI coding assistant: ~€20/mo.
- **AI model usage (key variable):** ~€0.15–0.50 per mock interview. Price the product well
  above this; use a cheaper model for the chat and a stronger one only for feedback.
- Code execution: keep near €0 by running it in the browser.

**Rough total: ~€40–80/mo + model usage; ~€100–200 across this phase.**

## Phase 3 — Soft launch & first users  *(Weeks 10–14)*

Open to the newsletter audience and communities. Offer a free first session, convert to
paid, gather feedback and testimonials. Decide pricing: freemium (one free mock, then pay),
a €10–20/mo subscription, or credit packs.

**Cost: ~€0–50**, mostly time.

## Phase 4 — Monetise & iterate  *(Months 3–5)*

Refine pricing on what converts, add a second interview type **only if the first sells**,
build case studies, keep growing the newsletter. Steady revenue should begin here.

**Cost: ~€40–100/mo**, scaling with users — now offset by income.

## Phase 5 — Advertising & growth  *(Month 4+, after demand is confirmed)*

- **Free/low-cost first:** SEO content, community posts, newsletter cross-promotions, a
  Product Hunt launch. ~€0.
- **Paid test:** Reddit ads and Google search ads on high-intent terms. €100–300 to test;
  expect competitive cost-per-click (~€1–5).
- **Newsletter sponsorships:** ~€50–300 per placement.
- **Reality:** €1,000 doesn't fund much paid advertising. Early growth is mostly organic;
  treat ads as a small experiment, then reinvest real revenue into what works.

## Budget allocation (~€1,000)

| Item | Rough cost |
| --- | --- |
| Domain + landing page + newsletter (year 1) | ~€50 |
| Tools + hosting + AI usage (~6 months) | ~€300–400 |
| Small paid-ads test | ~€150–300 |
| Reserve / buffer | ~€200–300 |
| **Total** | **Within €1,000** |

## Timeline & honest expectations

At 10–20 h/week: prototype in ~2 weeks, MVP around weeks 8–10, first paying users around
month 3, and *potentially* a few hundred euros/month by months 4–6. None of this is
guaranteed — it depends on whether the tool solves a real, painful problem and on
consistent marketing. The biggest risk is building too much before validating demand,
which is why the prototype and landing page come first.

## Immediate next step

Build the AI interviewer for **one** format. Recommended: the **AI-assisted coding round** —
the newest format, least existing prep, natural fit for an AI tool. System design is a
strong alternative (high value, common source of anxiety).
